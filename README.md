SALES TRANSACTION ANALYSIS

    Questions answered
- How does the monthly revenue change over time?
- Which products generate the most revenue?
- What is the average order value, total revenue, and total orders?
- Number of duplicates?

    Dataset
file: Sales_transactions_2022_2025.csv
source: kaggle - https://www.kaggle.com/datasets/danielsowah123/retail-sales-dataset
size: 36 columns and 19045 rows

    TOOLS USED
- Python (pandas, matplotlib)
- Jupyter Notebook

    Charts
- Line chart of monthly revenue
- Horizontal barchart of products

How to run
1. Clone the repository
2. Install the required software (pandas, matplotlib, and jupyter notebook)

command in terminal 'python -m pip install pandas matplotlib jupyterlab'

3. Open 'analysis.ipynb' and run all cells
